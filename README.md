# car_analysis
Proyecto del Sprint 7
Descripción del Proyecto
Nombre del Proyecto: Análisis de Anuncios de Coches

Descripción: Esta aplicación web tiene como objetivo proporcionar una herramienta interactiva para analizar datos de anuncios de coches en Estados Unidos. Utilizando el conjunto de datos vehicles_us.csv, la aplicación permite a los usuarios explorar y visualizar información relevante sobre los vehículos en venta.

Funcionalidad: La aplicación ofrece las siguientes funcionalidades principales:

Visualización de Datos:

Histograma: Los usuarios pueden generar un histograma interactivo para analizar la distribución de una variable específica, como el odómetro.

Gráfico de Dispersión: Los usuarios pueden crear un gráfico de dispersión para explorar la relación entre dos variables, como el odómetro y el precio del vehículo.

Interfaz Interactiva:

La aplicación incluye botones y/o casillas de verificación que permiten a los usuarios generar visualizaciones de manera sencilla e intuitiva.

Análisis Exploratorio:

La aplicación permite realizar análisis exploratorio de datos, lo que facilita la identificación de tendencias y patrones en los anuncios de coches.
