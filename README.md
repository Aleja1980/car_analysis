# 🚘 Car Analysis | Análisis de Anuncios de Coches

## 📘 Overview (English)

This web application provides an interactive tool to analyze car listing data from the United States. Built using the `vehicles_us.csv` dataset, it enables users to explore key vehicle attributes and visualize trends. Features include histograms, scatter plots, and an intuitive interface for exploratory data analysis.

---

## 📘 Descripción del Proyecto (Español)

**Nombre del Proyecto:** Análisis de Anuncios de Coches

Esta aplicación web tiene como objetivo proporcionar una herramienta interactiva para analizar datos de anuncios de coches en Estados Unidos. Utilizando el conjunto de datos `vehicles_us.csv`, la aplicación permite a los usuarios explorar y visualizar información relevante sobre los vehículos en venta.

### ⚙️ Funcionalidad

#### 📊 Visualización de Datos
- **Histograma:** Generación de histogramas interactivos para analizar la distribución de variables como el odómetro.
- **Gráfico de Dispersión:** Creación de gráficos de dispersión para explorar relaciones entre variables, como el odómetro y el precio.

#### 🖱️ Interfaz Interactiva
- Botones y casillas de verificación permiten generar visualizaciones de forma intuitiva y dinámica.

#### 🔍 Análisis Exploratorio
- La aplicación facilita la identificación de tendencias y patrones en los anuncios de coches mediante técnicas de análisis exploratorio.
